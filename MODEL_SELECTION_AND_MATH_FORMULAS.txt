3. MATHEMATICAL FORMULAS FOR VRAM, TOKENS & SCALING
================================================================================

--------------------------------------------------------------------------------
3.1 Model Weight Memory Formula
--------------------------------------------------------------------------------
Calculates the VRAM required to load the model parameters into GPU memory:

    VRAM_weights (GB) = [ (P * b_weight) / (8 * 10^9) ] * 1.15

Where:
    - P = Parameter count (e.g., 32.5 * 10^9 for a 32B model)
    - b_weight = Bits per weight (e.g., 4.5 bits for Q4_K_M, 8 bits for Q8, 16 bits for FP16)
    - 1.15 = 15% runtime CUDA context, activation buffers, and scratchpad overhead


--------------------------------------------------------------------------------
3.2 KV-Cache Memory Formula (Scaling x Input Tokens -> y Output Tokens)
--------------------------------------------------------------------------------
When you send x input tokens and the model generates y output tokens, the total
context length is:
    C = x + y

The Key-Value (KV) cache stores attention matrices across all layers:

    VRAM_KV_Cache (Bytes) = 2 * L * H_kv * D_head * C * b_precision

Where:
    - L = Number of Transformer Layers (e.g., 64 layers for Qwen-32B)
    - H_kv = Number of Key-Value Heads (with Grouped-Query Attention GQA, H_kv = 8)
    - D_head = Head Dimension (typically 128)
    - C = Total tokens (x + y)
    - b_precision = Bytes per cache element (2 bytes for FP16, 1 byte for FP8)

Simplified KV-Cache Constant per 1,000 Tokens (for 32B GQA Model):
    - In FP16 Precision = 0.131 GB per 1,000 tokens
    - In FP8 Precision  = 0.065 GB per 1,000 tokens

Context Length (C = x + y)     KV-Cache VRAM (FP16)      KV-Cache VRAM (FP8)
----------------------------------------------------------------------------
8,192 tokens (8k)              1.07 GB                   0.53 GB
16,384 tokens (16k)            2.15 GB                   1.07 GB
32,768 tokens (32k)            4.29 GB                   2.15 GB
65,536 tokens (64k)            8.58 GB                   4.29 GB
131,072 tokens (128k)          17.16 GB                  8.58 GB


--------------------------------------------------------------------------------
3.3 Total VRAM Usage Formula
--------------------------------------------------------------------------------
The complete system constraint must satisfy:

    Total_VRAM = VRAM_weights + VRAM_KV_Cache(x + y) + VRAM_embedding + VRAM_reranker + Overhead <= 32.0 GB


--------------------------------------------------------------------------------
3.4 Dynamic Context Budget Allocation Formula
--------------------------------------------------------------------------------
To prevent context overflow and maintain maximum reasoning quality:

    Budget_evidence = Budget_total - (Tokens_system + Tokens_tool_schemas + Tokens_chat_history + Tokens_reserve_output)


--------------------------------------------------------------------------------
3.5 Token Density & Estimation Formula on Any Data Type
--------------------------------------------------------------------------------
Calculates raw tokens x across any document or file type:

    x = SUM [ Length_chars(j) * rho_type ]

Where rho_type is the Token Density Ratio:
    - Plain Text:        rho = 0.250 tokens/char (~4.0 chars/token)
    - Code (Python/JS):  rho = 0.312 tokens/char (~3.2 chars/token)
    - JSON / Key-Value:  rho = 0.357 tokens/char (~2.8 chars/token)
    - PDF / Scanned OCR: rho = 0.222 tokens/char (~4.5 chars/token)


--------------------------------------------------------------------------------
3.6 The 1M Token Corpus Multi-Stage Compression Formula
--------------------------------------------------------------------------------
Calculates how 1,000,000 raw tokens are compressed into a compact reasoning context:

    T_final = T_raw * PROD [ 1 - r_i ]
            = T_raw * (1 - r_search) * (1 - r_rerank) * (1 - r_dedup) * (1 - r_progressive) * (1 - r_semantic)

Example for 1M Tokens (1,000,000 tokens):
    T_final = 1,000,000 * (1 - 0.96) * (1 - 0.80) * (1 - 0.30) * (1 - 0.40) * (1 - 0.35)
            = 1,000,000 * (0.04 * 0.20 * 0.70 * 0.60 * 0.65)
            = 1,000,000 * 0.002184
            = 2,184 Tokens (99.78% Reduction!)


--------------------------------------------------------------------------------
3.7 Word Importance & Retention Scoring Formula (Save vs Drop Rule)
--------------------------------------------------------------------------------
Every word/token w is assigned an Information Salience Score S(w):

    S(w) = alpha * BM25(w, Q) + beta * AttentionWeight(w, Q) + gamma * I_critical(w)

Where:
    - alpha = 0.35, beta = 0.35, gamma = 0.30
    - BM25(w, Q) = Exact keyword match score against query Q
    - AttentionWeight(w, Q) = Cross-attention relevance from Reranker
    - I_critical(w) = Critical Entity Indicator:
        * I_critical = 1.0 for numbers, dates, versions, error codes, function names
        * I_critical = 1.0 for negations ('not', 'never', 'must', 'only')
        * I_critical = 0.0 for stopwords, conversational filler

Retention Rule:
    - If S(w) >= 0.60  ==> KEEP TOKEN
    - If S(w) <  0.60  ==> DROP TOKEN


--------------------------------------------------------------------------------
3.8 BM25 Exact Keyword Value Formula
--------------------------------------------------------------------------------
    BM25(w, D) = IDF(w) * [ f(w, D) * (k1 + 1) ] / [ f(w, D) + k1 * (1 - b + b * (|D| / avgdl)) ]

Where:
    - IDF(w) = ln[ (N - n(w) + 0.5) / (n(w) + 0.5) + 1 ]
    - f(w, D) = Term frequency of word w in document D
    - k1 = 1.5, b = 0.75


--------------------------------------------------------------------------------
3.9 Generation Speed & Latency Formula
--------------------------------------------------------------------------------
    Total_Time = T_prefill(x) + T_decode(y)

    1. T_prefill = (2 * P * x) / GPU_TFLOPS
    2. T_decode  = y * [ Model_Size_Bytes / Memory_Bandwidth_Bytes_Per_Sec ]

On RTX 5090 (1,790 GB/s bandwidth, 20 GB Model):
    Time_per_token = 20 GB / 1,790 GB/s = 0.0111 s/token (90 tokens/sec)
